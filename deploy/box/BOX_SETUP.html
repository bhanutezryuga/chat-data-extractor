Capture box setup

Turn an old laptop into the always-on capture server, reachable only over your Tailscale network. Placeholders: you@example.com is your Tailscale login, <tailnet> is your tailnet name.

Steps, in order

  1. Install Ubuntu Server 24.04 on the old laptop. Enable the OpenSSH server option so you can finish from your main machine.
  2. Clone the repo to /srv/chat-data-extractor: 
    sudo git clone <repo-url> /srv/chat-data-extractor
sudo chown -R "$USER": /srv/chat-data-extractor
cd /srv/chat-data-extractor
  3. Run the setup script. It installs Docker, Tailscale and unattended upgrades, lets the lid close without sleeping, and joins the tailnet as capture (it prints a login link). 
    sudo deploy/box/setup.sh
    Then log out and back in so the docker group applies.
  4. In the Tailscale admin console, enable MagicDNS and HTTPS certificates (DNS page). Do this before step 7, or the certificate step will fail.
  5. Create the env file. Copy the example and set your Tailscale login email: 
    cp capture/capture.env.example capture/capture.env
# edit capture.env:
CAPTURE_ALLOWED_LOGINS=you@example.com
    Several logins can be comma-separated. An empty list refuses everyone. The file is git-ignored. The setup script already created data-capture/ owned by UID 1000. If you set CAPTURE_DATA_DIR to another path, create that directory yourself and make it owned by UID 1000 (sudo install -d -o 1000 -g 1000 /path), or the containers cannot write the database and will keep restarting.
  6. Start the app: 
    docker compose -f capture/compose.yaml up -d --build
  7. Publish it on the tailnet: 
    sudo tailscale serve --bg 8000
    The app listens on 127.0.0.1:8000 only; Tailscale is the only way in.
  8. Install Tailscale on the phone and on the laptop, signed in to the same account. Make Tailscale always on (phone): open Android Settings → Network & internet → VPN, tap the ⚙ next to Tailscale, and turn on Always-on VPN. (Menu names vary a little by phone maker; search Settings for "VPN" if you can't find it.)
  9. Open https://capture.<tailnet>.ts.net on both.

Check it worked

  • On the box: docker compose -f capture/compose.yaml ps shows web as healthy.
  • On the box: curl -s http://127.0.0.1:8000/healthz prints {"ok":true}.
  • On the phone: the https address above loads over mobile data with Wi-Fi off.

Install on your phone

  1. Open https://capture.<tailnet>.ts.net in Chrome on Android.
  2. Tap ⋮ → Add to Home screen → Install.
  3. "Capture" now appears in the share sheet. In Instagram, tap Share; if Capture isn't in the first row of the share sheet, scroll the row or tap More.
  4. Keep Tailscale on Always-on VPN (see step 8 above) so shares reach the box.

Phone check

  • ☐ 1. Install the app from Chrome. "Capture" appears in Instagram → Share → More.
  • ☐ 2. Share a reel. "Saved ✓" shows and closes. Within a minute the item has a title on the Home list.
  • ☐ 3. Share the same reel again. There is still one item.
  • ☐ 4. Turn Tailscale off and share a different reel. You see "Saved on your phone…".
  • ☐ 5. Turn Tailscale on and open the app. The item appears and "shares waiting" disappears.
  • ☐ 6. Paste a link from the laptop browser. It appears with the "Saved ✓" banner.

Updating

cd /srv/chat-data-extractor && deploy/box/update.sh

Troubleshooting

You seeCause and fix
403 "Not allowed"The login you are signed in with is not in CAPTURE_ALLOWED_LOGINS in capture.env. Fix it, then run docker compose -f capture/compose.yaml up -d.
Certificate error in the browserHTTPS certificates are not enabled in the Tailscale admin console. Enable them, then run sudo tailscale serve --bg 8000 again.
Can't connect / times outTailscale is off on that device. Turn it on (phone: Always-on VPN, see step 8).
